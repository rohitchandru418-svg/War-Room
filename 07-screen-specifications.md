# 07 — Screen Specifications

---

## Screen 1: Dashboard (Home — Team Mode)

**Route:** `/dashboard`  
**Access:** Team Member, War Room Lead, War Room Admin, System Admin

### Layout Sections

#### 1A. Source Health Banner (top of page)
- Shows if any source is delayed or down: "X data delayed since 09:14" / "Puthiya Thalaimurai feed unavailable"
- Hidden when all sources are healthy
- Always visible — never behind a toggle

#### 1B. Entity Sentiment Cards (3 cards: TVK, CM Vijay, AadhavArjuna)
Each card shows:
- Entity name
- Sentiment percentage (weighted) + raw count ("of N mentions")
- Last updated timestamp
- Mini-sparkline of sentiment over last 24h
- If count < 30: "not enough data" (no percentage shown)
- Tap → opens entity drill-down (Mentions filtered for this entity)
- Weighted score tapped → shows raw count + top 3 contributing accounts

#### 1C. Ally Mood Panel
- Lists all ally/supporting parties
- Shows each party's mood indicator: positive / neutral / negative (toward TVK)
- Based on public figures from that party
- If mood is negative: highlighted in red with arrow to alert
- Tap party → opens Ally Detail View

#### 1D. Active Alerts (top 3)
- Shows at most 3 alerts ranked by severity
- Each alert shows: type badge, one-line description, timestamp, severity indicator
- Flashing animation for unacknowledged Tier 1 alerts
- "Taken by <name>" shown when acknowledged
- "All Alerts →" link opens Alerts screen
- Tap alert → opens Alert Detail

#### 1E. Rising Stories
- Lists top 3–5 rising Stories by mention velocity
- Each story: title, source breakdown ("N outlets, N posts"), age, trend arrow
- Tap → opens Story Detail

## Screen 2: Story Detail

**Route:** `/stories/:id`  
**Access:** Team Member and above

### Sections

#### 2A. Story Header
- Story title (auto-generated or staff-edited)
- Total reach: "N outlets, N posts"
- Source breakdown: X posts / news articles / e-paper / clippings
- Entity tags (which entities this Story mentions)
- Severity indicator
- Campaign link (if this Story is part of a detected campaign)

#### 2B. Timeline
- Chronological chart of Mention volume by source type
- Shows velocity (rate of new Mentions)

#### 2C. Mentions List
Sortable by: time, influence score, source type  
Each Mention row shows:
- Author name / Outlet name + tier badge
- Snippet of text (first 2 lines)
- Source type icon (X / news / e-paper / clipping)
- Language badge (Tamil / English / Tanglish)
- Sentiment label + reason (tap to expand)
- Engagement metrics (reposts, likes, views for X; outlet reach for news)
- Influence weight score
- Timestamp
- Link to original source
- "Correct label" button

#### 2D. Response Status
- TVK response status (has any TVK leader posted about this?)
- If in response queue: shows queue position and suggested response type

#### 2E. Staff Actions
- Merge with another Story
- Split Story
- Add to response queue
- Mark as "not needed"

## Screen 3: Alert Detail

**Route:** `/alerts/:id`  
**Access:** Team Member and above

### Sections

#### 3A. Alert Header
- Alert type: Volume Spike / Influence Trigger / Campaign Signal / Response Opportunity / Ally Mood
- Severity tier badge
- Timestamp (when fired)
- Status: active / acknowledged / assigned

#### 3B. Co-worker Explanation
- Two-line explanation generated by co-worker at alert time
- Example: "A verified national journalist with 1.2M followers posted a sharp criticism of CM Vijay. Engagement reached 4,000 reposts in 20 minutes."

#### 3C. Evidence
- For volume spikes: baseline vs. current chart + top driving posts
- For influence trigger: the specific post + account profile + engagement chart
- For campaign: account list, age distribution, shared phrasing, timing chart, confidence level
- For response opportunity: triggering content + list of who is reacting + TVK response status

#### 3D. Actions
- Acknowledge (clears flash for all users, records "taken by <name>")
- Assign to team member
- For campaign: Confirm Attribution button (War Room Lead only)

#### 3E. Acknowledgement History
- Timeline of: who acknowledged, who was assigned, when

## Screen 4: Campaign Detail

**Route:** `/campaigns/:id`  
**Access:** Team Member (read), War Room Lead (read + confirm)

### Sections

#### 4A. Campaign Header
- Status badge: "Possible Coordination" / "Confirmed: [party]" / "Dismissed"
- Confidence level (percentage with explanation)
- Entity targeted
- First detected timestamp

#### 4B. Evidence Panel
- Account list with: handle, age, follower count, bot-suspicion flag
- Shared phrasing (the near-identical text with differences highlighted)
- Timing chart (posts per minute, showing coordination burst)
- Network graph (accounts boosting each other) [PROPOSED — if technically feasible]

#### 4C. Spread Timeline
- Mentions per hour since first detection
- New accounts joining over time
- TVK response Stories (if any)

#### 4D. Attribution (War Room Lead only)
- "Confirm attribution to: [party]" (requires explicit party selection)
- Reason field (required)
- Submit → logged with name, reason, timestamp

## Screen 5: Co-worker Chat

**Route:** `/co-worker`  
**Access:** Team Member and above

### Sections

#### 5A. Chat Interface
- Text input (Tamil or English)
- TVK elephant avatar on co-worker messages
- Messages show timestamp and language used
- Each answer shows citations (tap citation → opens source Mention)
- "Useful / Not useful" thumbs on each co-worker answer

#### 5B. Answer Structure
- Main answer text
- Citation block: "Based on: [3 mentions] — tap to see"
- Sample size note when relevant: "Based on 64 posts"
- "Not enough data" message when applicable
- Suggested follow-up questions

#### 5C. Suggested Questions (sidebar or below input)
Pre-populated suggestions based on current state:
- "Why did Congress mentions turn negative today?"
- "What is driving the AadhavArjuna spike?"
- "Summarise the last 6 hours"
- "What response opportunities are open?"

## Screen 6: Upload Clippings

**Route:** `/uploads`  
**Access:** Team Member and above

### Sections

#### 6A. Upload Area
- Drag-and-drop zone or file picker
- Accepts: JPG, PNG, PDF image scans
- Mobile: camera capture option
- Multi-file upload supported

#### 6B. Per-Upload Form
- Outlet name (dropdown from known outlet list + "other" with text entry)
- Publication date (date picker, defaults to today)
- Page number (number input)
- Submit button

#### 6C. Processing Status
- Each upload shows: processing / OCR complete / Mention created / error
- Low-confidence OCR items shown with "check scan" badge
- Tap processed item → opens Mention Detail

## Screen 7: Admin — Configuration

**Route:** `/admin/config`  
**Access:** War Room Admin, System Admin

### Tabs

#### 7A. Watch Terms
- Per-entity list of watch terms
- Add / remove / edit terms (name, nickname, Tanglish spelling, hashtag)
- Instant save (no deploy required)

#### 7B. Standing Tiers
- Four tiers: National Media, State Media, Party Leaders, Influencers
- Per-tier list of handles
- Add / remove handles
- Audit log for all changes visible inline

#### 7C. Outlet Weights
- Per-outlet: tier assignment, independence flag (partisan / independent), reach estimate
- Edit inline
- Change history visible

#### 7D. Party Relationship Tags
- List of all parties with current tag
- Change tag via dropdown: ally / supporting / opposition / neutral
- Effect: immediate; history preserved for past periods

#### 7E. Alert Thresholds
- Per-alert-type: threshold values (e.g. Z-score threshold, minimum mentions, time window)
- Current value vs. default value shown
- Change logged with who/when

#### 7F. Alert Recipients
- WhatsApp numbers for each alert tier and entity
- Routing rules (e.g. response opportunities → Sajan)

#### 7G. Event Calendar
- Upcoming events (rally, assembly session, results day)
- Per event: date range, event-specific baseline (optional override)

## Screen 8: Admin — Platform Health

**Route:** `/admin/health`  
**Access:** War Room Admin, System Admin

### Sections

#### 8A. Source Status Table
- Per source: X API, each outlet/feed, e-paper subscription, AI model
- Status: healthy / delayed / down
- Last successful fetch time
- Error message if applicable

#### 8B. X API Usage
- Current month reads used vs. cap

#### 8C. WhatsApp Delivery Log

## Screen 9: Admin — Accuracy & Learning

**Route:** `/admin/accuracy`  
**Access:** War Room Admin, System Admin; accuracy trends also visible to War Room Lead

### Sections

#### 9A. Co-worker Stage Dashboard
- Per-capability card: Labelling (English / Tamil / Tanglish), Spike Alerts, Influence Alerts, Campaign Flags, Response Suggestions, Briefs
- Each card shows: current stage (Assist / Trusted / Co-worker), accuracy trend chart, accuracy vs. bar

#### 9B. Weekly Accuracy Chart
- Model-only accuracy vs. corrected accuracy
- Per language and per entity
- Week-over-week trend

#### 9C. Correction Rate Chart
- Corrections per 1,000 labels
- Broken down by language and entity
- Week-over-week trend (should be falling)

#### 9D. Filter Audit
- Missed-item rate from weekly audit samples
- Trend chart
- Link to current week's review queue

## Screen 10: Big Screen Mode

**Route:** `/bigscreen` (kiosk/display URL)  
**Access:** Wall display (no login required, but network-restricted)

- Full-width, high-contrast layout optimised for large displays
- Auto-refresh every 60 seconds (or on WebSocket push)
- Presentation-safe mode toggle: visible status indicator in corner
- Sections: Entity Sentiment Cards, Ally Mood Panel, Active Alerts (capped at 3), Rising Stories
- Flash animation on Tier 1 alert arrival
- Shows data-delay banners when sources are unhealthy

## Screen 11: CM Summary Mode

**Route:** `/cm-summary`  
**Access:** CM View role (read-only)

- Clean, minimal layout
- Summary card: at most 3 changes, one-line each
- Tap-to-expand for each change's evidence
- English or Tamil (preference-driven)
- "Reviewed by <name>" badge on ally attributions
- No correction controls
- No internal notes visible
